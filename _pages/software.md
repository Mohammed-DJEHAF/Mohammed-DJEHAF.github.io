## Temperature seasonality and cutaneous leishmaniasis in Algeria

Analysis data, MATLAB and Python code and numerical results that accompany the article *Temperature seasonality and spatially structured variation in cutaneous leishmaniasis in Algeria: a source-verified national panel, 2000–2024* (*Acta Tropica*, 2026), by K. Djehaf and M. A. Djehaf.

* Dataset and code on Zenodo: [10.5281/zenodo.21813194](https://doi.org/10.5281/zenodo.21813194)
* Source repository: [Mohammed-DJEHAF/algeria-climate-leishmaniasis](https://github.com/Mohammed-DJEHAF/algeria-climate-leishmaniasis)
* Article: [10.1016/j.actatropica.2026.108366](https://doi.org/10.1016/j.actatropica.2026.108366)

Code for the battery state-of-charge studies will be added here once the corresponding articles are published.
